Origem do tráfego
Nenhum preset salvo ainda.

Cole nome e ID exatamente como aparecem no gerenciador, separados por |. Sem esses IDs a Utmify não casa o depósito com o anúncio.

Transação

Os horários são convertidos para UTC no envio, como a API exige. Para reenviar e atualizar um status, repita o mesmo orderId e o mesmo createdAt.

Jogador

O IP é opcional, mas melhora o casamento do clique com a venda. Se você já captura ele no evento de CAPI, use o mesmo valor.

Valores

O líquido não pode ser zero. Se quiser que o lucro no dashboard reflita margem real em vez de volume depositado, coloque aqui o depósito multiplicado pela sua margem estimada.
